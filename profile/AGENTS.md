# Standing instructions

Colossus reads this file at the start of every session, in every folder. Anything
written here applies to all work.

No standing instructions are set yet.

To add some, replace this text with your own. Useful things to put here: the voice and
tone to write in, words or phrasings to avoid, how you want drafts structured, and which
skill to reach for by default on a given kind of task.
